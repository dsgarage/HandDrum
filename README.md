# hand-drum-player — 指先でドラムコーパスを演奏する Max パッチ

Web カメラのハンドトラッキングで両手 10 指を追跡し、指を振り下ろす(タップする)と、
機械学習で作った「音色の地図」上の近くの音が鳴る演奏パッチです。

ドラムループ群をオンセットで自動スライス → MFCC 91 次元で解析 → UMAP で 2 次元に圧縮 →
kdtree の近傍検索で「指の位置に近い音色」を再生します。

## 必要環境

| 項目 | 内容 |
|---|---|
| Max | Max 9(Max 8 でも動作見込み・未検証) |
| OS | macOS(ハンドトラッキング external が macOS 専用) |
| パッケージ | **FluidCorpusManipulation (FluCoMa)** — Max の Package Manager から無償インストール |
| external | **sg.landmark_detector.mxo**(後藤英氏作・ONNX Runtime 同梱)— `~/Documents/Max 9/Packages/sg.landmark_detector/externals/` に配置 |
| カメラ | 内蔵/外付け Web カメラ |

> external の配置後、macOS の quarantine で読み込みがブロックされる場合は
> `xattr -dr com.apple.quarantine ~/Documents/Max\ 9/Packages/sg.landmark_detector` を実行してください。

## ファイル構成

```
hand-drum-player.maxpat   本体(解析〜演奏まで一体型・プレゼンテーションモードで起動)
hd.fingers.js             指先抽出・タップ検出・plotter 連携(パッチと同階層に置く)
hd.samplepath.js          起動時に <パッチのある場所>/sampleloop のフルパスを生成(同上)
sampleloop/               ここに好きな WAV(ドラムループ等)を入れる ← 既定の読込先
diag-corpus-load.maxpat   読込チェッカー(開くだけで sampleloop を読込→バッファ長を表示)※パス直書き
sound-check.maxpat        サウンドチェック(サイン波+コーパス再生)
sound-probe.maxpat        無音切り分けプローブ(開くと 1 秒後サイン波 / 4 秒後ドラム。
                          ドラムは hand-drum-player 側で [読込] 済みのときだけ鳴る)
```

> このフォルダ(HandDrum/)は単体で持ち運べる自己完結バンドルです。
> パッチ・js・sampleloop/ を**同じフォルダのまま**移動してください。
> sampleloop のパスはパッチの場所から起動時に自動生成されます(diag-corpus-load のみパス直書きのため要修正)。

## 使い方

1. `sampleloop/` フォルダにドラムループの WAV を入れる(まずは 20〜30 ファイル程度を推奨)
2. `hand-drum-player.maxpat` を開く — パス欄にはパッチと同階層の `sampleloop/` が自動でセットされます。
   別のフォルダを使う場合はテキスト欄にパスを書き換えてください
3. **[サンプル読込]** をクリック → 読込 → 解析 → コーパス保存まで**自動で実行**されます
   (ファイル数に応じて数秒〜数十秒固まって見えます。連打しない)
   → 右の plotter に「音色の地図」、上部に波形とスライスが表示される
4. スピーカーアイコンをクリックして音声 ON
5. **再生テスト A/B** で音が出ることを確認
6. **トグル ON** でカメラ起動 → 手をかざして指を振り下ろすと演奏できます

## コーパスの保存と読込(読込・解析のスキップ)

解析が完了すると、パッチ同階層の 4 ファイルへ**自動で保存**されます(手動の **[コーパス保存]** ボタンも残っています)。

```
corpus.sound.wav          連結済み音源バッファ
corpus.slicepoints.wav    スライス位置(32bit float。サンプル番号がそのまま入る)
corpus.kdtree.json        学習済み kdtree(近傍検索の本体)
corpus.normalized.json    2 次元データセット(plotter 表示用)
```

保存済みの corpus.* があれば、**次回からはパッチを開くだけで自動で復元されます**
(起動 1.5 秒後に読込。plotter の地図も再表示され、解析ランプが点灯します)。
手動でやり直したいときは **[コーパス読込]** ボタンでいつでも再読込できます。
サンプルを入れ替えたときは、従来どおり [読込] → Bang → [コーパス保存] で作り直してください。

## 画面の見方

- **ステータス(右下)**: パスチェック + 2 つのランプで状態を確認できます
  - パス: 起動時と読込時にフォルダの存在と音源ファイル数を検証(「パスOK: 音源 28 件」/「パスNG」)。
    NG のときは読込自体を中止するので、空のバッファを解析してしまう事故が起きません
  - 読込ランプ: `sampleloop/` の音源がバッファに入ると緑点灯(「読込済み: xx 秒」表示)
  - 解析ランプ: Bang での解析が完了すると緑点灯。新しいコーパスを読み込むと消灯し「未解析」に戻ります
- **plotter(音色の地図)**: 黒い点 = 各スライス。似た音色ほど近くに配置されます(UMAP)。
  軸に意味はなく「距離」に意味があります
- **指カーソル**: 左手 = 赤/橙/緑/青/紫、右手 = 黄/シアン/マゼンタ/ライム/ピンク
- **タップした点**: その指の色に変わり少し大きくなります(=その指が今つかんでいる音)

## 調整(js へメッセージを送る)

| 症状 | メッセージ |
|---|---|
| タップの反応が鈍い | `threshold 0.02`(小さいほど敏感) |
| 誤検出が多い | `threshold 0.05` / `refractory 200` |
| カーソルの上下が逆 | `flipy 0` または `flipy 1` |
| 左右が逆 | `mirrorx 0` または `mirrorx 1` |
| コンソールでログ確認 | `taplog 1`（`debug` は js 予約メッセージのため使用不可） |
| 閉じた指の無効化を切りたい | `requireextended 0`(既定 1: 伸びた指のみ演奏可) |
| 伸展判定の厳しさ | `extratio 1.3`(大きいほど「しっかり伸ばした指」だけ有効。既定 1.15) |

## 既知の注意点

- 解析データはメモリ上のみです。パッチを開き直したら **[コーパス読込]**(保存済みの場合)か
  **[読込] → Bang** をやり直してください
- カメラ(30fps)+ 推論のため 50ms 前後のレイテンシがあります。
  「正確なドラム演奏」ではなく「音色空間を手で探る楽器」としてお楽しみください
- スライスが 15 個未満だと UMAP がエラーになります(近傍点数の既定が 15 のため)。
  素材は合計 1 分以上を目安に
